## 🧠 What I'm Covering

### 1. Python
- Syntax, data types, loops, conditionals
- Functions, modules, and packages
- Object-oriented programming
- Error handling and file I/O
- List comprehensions, lambda, generators, decorators

### 2. Data Analysis
- **NumPy**: arrays, vectorization, broadcasting
- **Pandas**: DataFrames, cleaning, grouping, merging
- **Matplotlib / Seaborn**: data visualization

### 3. Machine Learning
- Supervised learning: Linear/Logistic Regression, Decision Trees, Random Forest, SVM, KNN
- Unsupervised learning: K-Means, PCA
- Feature engineering, train/test split, cross-validation
- Metrics: accuracy, precision, recall, F1, RMSE, ROC-AUC

### 4. Deep Learning
- Neural network fundamentals: perceptron, backpropagation, activation functions
- Optimizers and loss functions
- CNNs for image tasks
- RNNs, LSTMs, GRUs for sequence data

### 5. NLP
- Text preprocessing: tokenization, stemming, lemmatization, stop words
- Bag of Words, TF-IDF
- Word embeddings: Word2Vec, GloVe
- Transformers and pre-trained models (BERT, GPT-style models)
- Text classification, sentiment analysis, named entity recognition

## 🚀 Getting Started

### Prerequisites
- Python 3.9 or higher
- pip
- Git

### Setup

```bash
# Clone the repository
git clone https://github.com/<your-username>/<repo-name>.git
cd <repo-name>

# Create a virtual environment
python -m venv venv

# Activate it
# Windows
venv\Scripts\activate
# macOS / Linux
source venv/bin/activate

# Install dependencies
pip install -r requirements.txt

# Launch Jupyter
jupyter notebook
```
